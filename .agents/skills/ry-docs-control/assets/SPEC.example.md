## 文档层级与维护

| 文档 | 写什么 | 不写什么 |

| `docs/INTENT.md` | 项目意图、边界、取舍、关键决策 | 操作步骤、结构细目 |
| `docs/ARCHITECTURE.md`（若存在） | 全局逻辑组件、职责、依赖、接口、数据所有权和跨模块不变量 | 项目目标、目录树、完整运行时序、模块内部设计 |
